## BarberBot — Telegram-бот для записи клиентов

Бот для записи в барбершоп (один мастер): клиент выбирает услугу, дату и время, подтверждает запись и получает напоминания. Администратор управляет записями, услугами и расписанием прямо из Telegram.

> Демо-проект. Название барбершопа, адрес и телефон вымышленные.

**Демо:** @your_demo_bot <!-- замени на ссылку на своего бота или удали строку -->

## Возможности

**Для клиента**
- Запись за 4 шага: услуга → дата → время → имя и телефон → подтверждение
- Показываются только реально свободные слоты (с учётом длительности услуги и уже существующих записей)
- «Мои записи»: просмотр и отмена (не позднее чем за 2 часа до визита)
- Напоминания за 24 часа и за 2 часа до визита
- Каталог услуг с ценами и контакты

**Для администратора** (`/admin`, доступ только по Telegram ID)
- Записи на сегодня, завтра и на любую дату, переключение дней стрелками
- Отмена записи с уведомлением клиента
- Управление услугами: добавить, изменить название, цену и длительность, отключить и включить
- Расписание: часы работы по дням недели, выходные дни недели, выходные даты (праздники, отпуск)
- Уведомления о каждой новой записи и отмене

## Стек

- Python 3.10+ (разрабатывалось на 3.13)
- [aiogram 3](https://docs.aiogram.dev/) (асинхронный Telegram Bot API, FSM, роутеры)
- SQLite через aiosqlite
- python-dotenv, tzdata

## Структура проекта

```
barberbot/
├── bot.py                # точка входа, сборка диспетчера, запуск
├── config.py             # настройки из .env

├── keyboards.py          # клавиатуры клиента

├── texts.py              # тексты
└── handlers/
    ├── menu.py           # /start, главное меню, услуги, контакты
    ├── booking.py        # цепочка записи (FSM)
    ├── my_bookings.py    # мои записи, отмена
    ├── admin.py          # админ-панель, записи по дням
    ├── admin_services.py # управление услугами

    └── fallback.py       # неизвестные сообщения и устаревшие кнопки
```

## Быстрый старт

```bash
git clone https://github.com/MalykhArtyom/barberbot.git
cd barberbot

python -m venv .venv
# Windows:      .venv\Scripts\activate
# Linux/macOS:  source .venv/bin/activate

pip install -r requirements.txt
cp .env.example .env      # затем заполни .env
python bot.py
```

### Настройки (`.env`)

| Переменная  | Описание                                                        |
|-------------|-----------------------------------------------------------------|
| `BOT_TOKEN` | токен бота от @BotFather                                        |
| `ADMIN_IDS` | Telegram ID администраторов через запятую (узнать: команда `/id` у бота) |
| `PROXY_URL` | прокси, если нужен, с протоколом: `http://host:port` или `socks5://host:port`; иначе оставить пустым |
| `DB_PATH`   | путь к файлу SQLite (по умолчанию `barber.db`)                  |
| `TIMEZONE`  | часовой пояс барбершопа, например `Asia/Yekaterinburg`          |

При первом запуске база создаётся автоматически и заполняется демо-данными: 4 услуги и расписание пн-сб 10:00-20:00.

## Как это устроено

- **Свободные слоты.** Для выбранной услуги берутся рабочие часы дня, из них вычитаются интервалы существующих записей (с учётом длительности каждой услуги). Сетка начала слотов шаг 30 минут, запись возможна не позднее чем за 60 минут до визита.
- **Защита от двойной записи.** Перед сохранением слот перепроверяется внутри транзакции `BEGIN IMMEDIATE`: если два клиента одновременно выберут одно время, второй получит предложение выбрать другое. Дополнительно в БД стоит уникальный индекс на активные слоты.
- **Лимиты.** Не более 3 активных записей на клиента, ограничения на ввод имени, телефона и данных услуг.
- **Напоминания.** Фоновая задача раз в минуту проверяет ближайшие записи. Флаги отправки хранятся в БД, поэтому после перезапуска бота напоминания не дублируются и не приходят «за сутки» за час до визита.
- **Права администратора.** Фильтр `IsAdmin` навешен на весь админский роутер, поэтому новые админские кнопки защищены по умолчанию.
- **Устойчивость.** Глобальный обработчик ошибок, ротация логов (`bot.log`), корректная обработка устаревших кнопок и заблокировавших бота клиентов.

## Запуск на сервере (Linux, systemd)

Пример unit-файла `/etc/systemd/system/barberbot.service`:

```ini
[Unit]
Description=BarberBot
After=network-online.target
Wants=network-online.target

[Service]
User=botuser
WorkingDirectory=/home/botuser/barberbot
ExecStart=/home/botuser/barberbot/.venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now barberbot
sudo journalctl -u barberbot -f      # логи
```
